# KeyCraft — многостраничный сайт интернет-магазина

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина механических клавиатур KeyCraft. Проект выполнен без CSS-фреймворков. JavaScript используется минимально — только для открытия и закрытия модального окна заявки и базовой проверки формы.

## Ссылка на опубликованный проект

GitHub Pages: https://kurligin.github.io/kr1-html-css-shop/

## Описание

KeyCraft — учебный интернет-магазин механических клавиатур, свитчей и кейкапов. Пользователь может посмотреть популярные товары на главной, перейти в каталог с фильтрами, открыть страницу товара с характеристиками и отзывами и оставить заявку — в модальном окне или на отдельной странице.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт модального окна и обработки формы;
- `images/` — SVG-иллюстрации товаров;
- `sitemap.xml` — карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Обязательные страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | hero-блок, преимущества, популярные товары, модальное окно заявки |
| `catalog.html` | каталог из шести товаров в двух категориях, блок фильтров |
| `product.html` | изображение, описание, таблица характеристик, таблица сравнения, отзывы, частые вопросы |
| `order.html` | форма оформления заявки и порядок работы с заказом |
| `contacts.html` | телефон, e-mail, адрес шоурума, часы работы, обратная связь |

У каждой страницы свой `title`, свой `meta description`, общая навигация и общий CSS-файл.

## Навигация

- единое меню из пяти страниц на всех страницах сайта;
- активный пункт меню выделен модификатором `site-nav__link--active` и атрибутом `aria-current="page"`;
- якорные ссылки на разделы главной страницы: `#advantages`, `#popular`;
- якоря внутри каталога: `#keyboards`, `#parts`;
- якоря на странице товара: `#specs`, `#compare`, `#reviews`, `#faq`;
- подвал доступен по якорю `#contacts`;
- навигационная цепочка на внутренних страницах;
- быстрые ссылки на разделы в подвале;
- плавная прокрутка к якорям и подсветка раздела через `:target`;
- фиксированная кнопка «Наверх» на всех страницах.

## CSS-архитектура

Файл `css/style.css` разделён на смысловые блоки:

1. Переменные проекта.
2. Базовые стили.
3. Кнопка.
4. Шапка и навигация.
5. Разделы страницы.
6. Товары.
7. Каталог.
8. Форма заявки и модальное окно.
9. Карточка: изображение и бейджи.
10. Страница товара.
11. Таблицы.
12. Отзывы и частые вопросы.
13. Страница заявки.
14. Подвал и кнопка «Наверх».

В проекте используются:

- CSS-переменные в `:root`: цвета, шкала отступов, скругления, ширина контейнера;
- состояния `:hover`, `:focus-visible`, `:disabled`, `:target`;
- Flexbox для шапки, меню, карточек, кнопок формы;
- CSS Grid для сетки товаров, каталога, страницы товара, страницы заявки и блока отзывов;
- позиционирование: `relative` у карточки, `absolute` у бейджа, `sticky` у панели фильтров, `fixed` у кнопки «Наверх», `z-index` у бейджей и кнопки.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — навигационная цепочка;
- `page` — основная область страницы;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `advantages-list` — список преимуществ;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product` — карточка товара на отдельной странице;
- `specs-table` — таблица характеристик и сравнения;
- `reviews`, `review` — блок отзывов;
- `faq` — частые вопросы;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters`, `filters-form` — фильтры каталога;
- `order-layout`, `order-aside`, `order-steps` — страница заявки;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `success-message` — сообщение об успешной отправке;
- `aside-info` — дополнительный информационный блок;
- `contacts-list` — контактные данные;
- `button` — кнопка;
- `scroll-top` — кнопка «Наверх»;
- `site-footer` — подвал сайта.

Примеры элементов и модификаторов:

- элементы: `site-nav__link`, `product-card__title`, `product-card__price`, `order-form__field`, `specs-table__caption`, `breadcrumbs__current`;
- модификаторы: `site-nav__link--active`, `button--primary`, `button--secondary`, `product-card--hit`, `product-card--new`, `product-card--soon`, `order-form__field--checkbox`.

Стили задаются классами: селекторов вида `.блок тег`, стилизации через `id` и inline-стилей в проекте нет.

## Самостоятельные доработки

Сверх требований методических указаний в проект добавлено следующее.

**Содержание и структура**

- собственная предметная область: магазин механических клавиатур вместо абстрактных «Товар 1, 2, 3»;
- каталог расширен до шести позиций и разделён на две категории с отдельными якорями;
- страница товара дополнена блоком отзывов и блоком частых вопросов на элементе `details`, который работает без JavaScript;
- таблица сравнения трёх моделей клавиатур в дополнение к таблице характеристик;
- страница заявки дополнена боковым блоком с порядком работы с заказом.

**Интерфейс**

- собственные SVG-иллюстрации товаров вместо растровых изображений: они не теряют качество и весят меньше килобайта;
- бейджи «Хит», «Новинка» и «Скоро в продаже» через модификаторы карточки;
- второстепенный вариант кнопки `button--secondary`;
- фиксированная кнопка «Наверх» и закреплённая при прокрутке панель фильтров;
- подвал с контактами и быстрыми ссылками на разделы;
- на узких экранах многоколоночные блоки перестраиваются в одну колонку, широкие таблицы прокручиваются по горизонтали.

**Доступность**

- видимый фокус у всех интерактивных элементов через `:focus-visible`;
- `aria-current="page"` на активном пункте меню;
- `aria-label` у обоих блоков навигации, чтобы их можно было различить;
- `aria-invalid` на полях с ошибками и `role="status"` у сообщения об успешной отправке;
- подписи `label` у всех полей формы, связанные через `for` и `id`;
- текстовые альтернативы у всех изображений.

**Качество кода**

- CSS разделён на четырнадцать именованных блоков;
- все цвета, отступы и скругления вынесены в переменные `:root`;
- БЭМ применён последовательно, повторяющихся правил нет.
