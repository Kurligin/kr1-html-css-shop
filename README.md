# KeyCraft — учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина механических клавиатур KeyCraft.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт модального окна и обработки формы;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта;
- `sitemap.xml` — простая карта сайта.

## Используемые технологии

- HTML;
- CSS;
- JavaScript;
- Git;
- GitHub.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- скрытое поле с названием выбранного товара;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

## Навигация

- единое меню на всех страницах;
- якорные ссылки на главной странице: `#advantages`, `#popular` и `#contacts` (подвал с контактами);
- ссылки вида `index.html#popular` с внутренних страниц;
- навигационная цепочка (breadcrumbs) на страницах каталога и контактов;
- уникальные `title` и `meta description` у каждой страницы;
- плавная прокрутка к якорям и подсветка раздела через `:target`.

## Дополнительные элементы

- `sitemap.xml` — простая карта сайта.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для шапки и основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## CSS-архитектура

Файл `css/style.css` разделён на смысловые блоки:

1. Переменные проекта.
2. Базовые стили.
3. Кнопка.
4. Шапка и навигация.
5. Разделы страницы.
6. Товары.
7. Каталог.
8. Форма заявки и модальное окно.

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- основная и второстепенная кнопки (`.button--primary`, `.button--secondary`);
- визуальная подсветка ошибочных полей через `aria-invalid`.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — навигационная цепочка;
- `page` — основная область страницы;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `advantages-list` — список преимуществ;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `success-message` — сообщение об успешной отправке;
- `aside-info` — дополнительный информационный блок;
- `contacts-list` — контактные данные;
- `button` — кнопка;
- `site-footer` — подвал сайта.

Примеры элементов и модификаторов:

- элементы: `site-nav__link`, `product-card__title`, `product-card__price`, `order-form__field`, `breadcrumbs__current`;
- модификаторы: `site-nav__link--active`, `button--primary`, `button--secondary`, `order-form__field--checkbox`.

Модификатор `button--disabled` описан в стилях для визуально отключённой кнопки и применяется к ссылкам, у которых нет атрибута `disabled`.

Стили задаются классами: селекторов вида `.блок тег` и стилизации через `id` в проекте нет.
